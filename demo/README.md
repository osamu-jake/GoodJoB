# demo/ — 参考実装（本番のコードではありません）

じゃけが5文書を書きながら先行して作った動くPoCです。**「完成したらこう動く」を見るためのもの**で、
ここを直して本番にするものではありません。

本番の実装は **`app/`** に、ぐんさん（フロント）・べー（バック）がそれぞれの担当領域として書きます。
`demo/` は読んで参考にするのは自由ですが、**そのままコピーして終わりにしないでください。**
仕様を自分で読んで手を動かすことで初めて気づくことがあり、そこが今回いちばん残したい部分です（ADR-0033）。

## 何のためにあるか

- 文書だけでは見つからない穴を先に踏むために作った。実際、ここから ADR-0021・0023〜0027 が出ている
  （`title`を埋め込むと正解が1位から3位に落ちる、表示%が降順にならない、など）
- 5文書に書いてあることが本当に動くのかを、9/30のMTG前に確かめるため

## 動かし方

```bash
cd demo
pip3 install -r requirements.txt
python3 -m streamlit run app.py
```

初回は埋め込みモデル（`intfloat/multilingual-e5-small`・約470MB）のダウンロードと、
`knowledge.db` の構築＋埋め込み計算が走るので数分かかります。2回目以降は既存のDBを使います。

```bash
python3 db/build_db.py --rebuild   # seeds.sql から作り直す
python3 tools/check_gap.py         # デモ用クエリの実測（ADR-0026の2本立て）
python3 tools/export_seeds.py      # knowledge.db → fixtures/seeds.sql
```

## 既知の問題（本番実装では直すこと）

| | |
|---|---|
| `search/scoring.py` の関連度% | 検索結果内のmin-max変換なので、**1位は必ず96%になる**。無関係なクエリでも96%「近い」と出る。**→ ADR-0035でコサイン類似度そのものを出す方針に決定。`demo/`は直さないので、`app/`では最初からコサイン類似度で実装すること** |
| `ui/` のカード→詳細 | `st.tabs`にタブを切り替えるAPIが無く、現状は`st.toast`を出すだけで遷移していない（I-08が通らない）。**方式（モーダル／ラジオ切替2画面／他）はぐんさんが実装しながら検討し、じゃけに提案→承認の形で決める（ADR-0034）** |
| ~~`requirements.txt`~~ | **解決済み。ADR-0036で`==`固定に変更**（`streamlit==1.64.0`／`numpy==1.26.4`／`janome==0.5.0`／`sentence-transformers==6.1.0`）。1.64で全APIの動作を確認済み |
| `evaluations` / `tech_usage` | どちらも技術だけが主語で「企画」がテーブルに無い。「技術Aは企画Xでは採用、企画Yでは不採用」が表現できない（べーさんの指摘）。**統合の要否はべーさんと相談して決める（未決）** |
| シーズ20件・ニーズ10件 | すべてプレースホルダ。原文URLは`example.invalid`。実特許への差し替えは未着手 |

## 正本

仕様の正本は `docs/5文書/` です。ここのコードと文書が食い違っていたら、**文書が正しい**と考えて
PMに確認してください（コードを黙って文書に合わせない。ADR-0024で一度、文書に書かれていない機能が
実装から消えた事故があります）。
